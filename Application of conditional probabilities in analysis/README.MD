# Применение условных вероятностей в анализе данных: Футбольная статистика
---  
Однажды один профессиональный скаут по имени Алексей решил:
> «А что, если можно узнать что-то неочевидное про игроков — просто глядя на цифры?» 
Он взял файл с данными о футболистах — возраст, рост, клуб, позиция, нога, рейтинг. И начал считать.

Возникали обыкновенные вопросы:
 * Если игрок играет в защите — насколько вероятно, что он высокий? 
 * Если он левша — чаще ли он играет слева? 
 * Какова вероятность, что нападающий забивает много, если его рейтинг выше 80? 

Он использовал простые формулы вероятности для подсчёта: 

$$  P(A) = \frac{\text{число случаев А}}{\text{число игроков}} $$

И когда вопрос стал сложнее — перешёл к формуле Байеса:

$$  P(A|B) = \frac{P(B|A) * P(A)}{P(B)} $$

Посмотрим, на какие вопросы смог ответить скаут Алексей с помощью теории вероятности:  
Ссылка на датасет: https://www.kaggle.com/datasets/maso0dahmed/football-players-data
---

| Признак | Тип | Описание | Проблемы | Потенциал для Feature Engineering |
|---------|-----|----------|----------|----------------------------------|
| `name` | Текстовый | Имя игрока | Может содержать дубликаты или сокращения | Можно извлечь фамилию, использовать как идентификатор |
| `birth_date` | Текстовый | Дата рождения (формат MM/DD/YYYY) | Неправильный формат, возможны ошибки | Преобразовать в возраст, извлечь месяц/год рождения |
| `age` | Числовой | Возраст на момент данных | Может быть некорректным (например, 2011 год) | Группировка по возрасту: молодой (<23), зрелый (23–30), ветеран (>30) |
| `height_cm` | Числовой | Рост в сантиметрах | Пропуски, выбросы | Бининг (низкий, средний, высокий), нормализация |
| `weight_kgs` | Числовой | Вес в килограммах | Пропуски, выбросы | Отношение вес/рост, бининг |
| `positions` | Текстовый | Позиции игрока (через запятую, напр. "ST,RW") | Много значений, неструктурированный | Разделение на столбцы, one-hot encoding, выделение основной позиции |
| `nationality` | Категориальный | Страна происхождения | Много уникальных значений | Группировка по регионам (Европа, Южная Америка и т.д.), кодирование |
| `overall_rating` | Числовой | Общий рейтинг игрока (0–100) | Выбросы, небольшой диапазон | Бининг: низкий (<70), средний (70–80), высокий (>80) |
| `potential` | Числовой | Потенциал развития (0–100) | Иногда равен `overall_rating` | Разница: `potential - overall_rating` — мера роста |
| `value_euro` | Числовой | Рыночная стоимость в евро | Очень широкий диапазон, выбросы | Логарифмирование, бининг, категоризация (миллионер, полумиллионер и т.д.) |
| `preferred_foot` | Категориальный | Основная нога: Left / Right | Есть пропуски | Бинарное кодирование (0/1) — удобно для анализа |
