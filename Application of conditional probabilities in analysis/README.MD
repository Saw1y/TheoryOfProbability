# Применение условных вероятностей в анализе данных: Футбольная статистика
---  
Однажды один профессиональный скаут по имени Алексей решил:
> «А что, если можно узнать что-то неочевидное про игроков — просто глядя на цифры?» 
Он взял файл с данными о футболистах — возраст, рост, клуб, позиция, нога, рейтинг. И начал считать.

Возникали обыкновенные вопросы:
 * Если игрок играет в защите — насколько вероятно, что он высокий? 
 * Если он левша — чаще ли он играет слева? 
 * Какова вероятность, что нападающий забивает много, если его рейтинг выше 80? 

Он использовал простые формулы вероятности для подсчёта: 

$$  P(A) = \frac{\text{число случаев А}}{\text{число игроков}} $$

И когда вопрос стал сложнее — перешёл к формуле Байеса:

$$  P(A|B) = \frac{P(B|A) * P(A)}{P(B)} $$

Посмотрим, на какие вопросы смог ответить скаут Алексей с помощью теории вероятности:

**Описание признаков в таблице**
| Признак | Тип | Описание | Проблемы |
|---------|-----|----------|----------|
| `name` | Текстовый | Имя игрока | Может содержать дубликаты или сокращения | 
| `birth_date` | Текстовый | Дата рождения (формат MM/DD/YYYY) | Неправильный формат, возможны ошибки | 
| `age` | Числовой | Возраст на момент данных | Может быть некорректным (например, 2011 год) | 
| `height_cm` | Числовой | Рост в сантиметрах | Пропуски, выбросы |
| `weight_kgs` | Числовой | Вес в килограммах | Пропуски, выбросы | 
| `positions` | Текстовый | Позиции игрока (через запятую, напр. "ST,RW") | Много значений, неструктурированный |
| `nationality` | Категориальный | Страна происхождения | Много уникальных значений |
| `overall_rating` | Числовой | Общий рейтинг игрока (0–100) | Выбросы, небольшой диапазон |
| `potential` | Числовой | Потенциал развития (0–100) | Иногда равен `overall_rating` | 
| `value_euro` | Числовой | Рыночная стоимость в евро | Очень широкий диапазон, выбросы | 
| `preferred_foot` | Категориальный | Основная нога: Left / Right | Есть пропуски |
