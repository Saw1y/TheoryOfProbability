# Применение условных вероятностей в анализе данных: Футбольная статистика
---  
Однажды один профессиональный скаут по имени Алексей решил:
> «А что, если можно узнать что-то неочевидное про игроков — просто глядя на цифры?» 
Он взял файл с данными о футболистах — возраст, рост, клуб, позиция, нога, рейтинг. И начал считать.

Возникали обыкновенные вопросы:
 * Если игрок играет в защите — насколько вероятно, что он высокий? 
 * Если он левша — чаще ли он играет слева? 
 * Какова вероятность, что нападающий забивает много, если его рейтинг выше 80? 

Он использовал простые формулы вероятности для подсчёта: 

$$  P(A) = \frac{\text{число случаев А}}{\text{число игроков}} $$

И когда вопрос стал сложнее — перешёл к формуле условной вероятности:

$$  P(A|B) = \frac{P(A * B)}{P(B)} $$

Посмотрим, на какие вопросы смог ответить скаут Алексей с помощью теории вероятности:  
Ссылка на датасет: https://www.kaggle.com/datasets/maso0dahmed/football-players-data

## Вычисление простых вероятностей 
Вычислим некоторые априорные вероятности по формуле: 

$$  P(A) = \frac{\text{число случаев А}}{\text{число игроков}} $$

1) Вероятность, что футболисту ровно 30 лет
```py
P_age_30 = (df['age'] == 30).mean()
print(f"P(age=30) = {P_age_30:.3f}")
```

$$ P(age = 30) = 0.050 $$

2) Вероятность быть правоногим или левоногим
```py
for foot in df['preferred_foot'].unique():
    P_foot = (df['preferred_foot'] == foot).mean()
    print(f"P({foot}) = {P_foot:.3f}")
```

$$ P(Left) = 0.232 $$


$$ P(Right) = 0.768 $$

3) Вероятность, что игрок — нападающий
```py
P_ST = df['positions'].str.contains('ST').mean()
print(f"P(position=ST) = {P_ST:.3f}")
```

$$ P(position=ST) = 0.177 $$ 

## Вычисление условных вероятностей

Условные вероятности определяются по формуле: 

$$  P(A|B) = \frac{P(A * B)}{P(B)} $$

1) Какова вероятность, что игрок — нападающий, если он правша?
``py 
# Способ 1: Вручную по формуле
right_footed = df[df['preferred_foot'] == 'Right']
P_Right = len(right_footed) / len(df)

strikers_right = right_footed[right_footed['positions'].str.contains('ST')]
P_ST_and_Right = len(strikers_right) / len(df)

P_ST_given_Right = P_ST_and_Right / P_Right
print(f"P(ST | Right), рассчитанная вручную: {P_ST_given_Right:.3f}")
```

$$ P(ST | Right) = 0.194 $$
