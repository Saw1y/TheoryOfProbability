# Парадокс Симпсона: Какого повысить в It компании?

## Условие 

В компании за год два программиста выполняли задачи двух типов:

* Простые (баги, правки) — много, сроки жёсткие.
* Сложные (новый функционал) — мало, сроки плавающие.

Статистика по типам:
```
Программист А:

Простые: 198/200 = 99%

Сложные: 18/20 = 90%
```
Вывод: Он лучше в каждом типе задач.
```
Программист Б:

Простые: 85/100 = 85%

Сложные: 72/100 = 72%
```
Вывод: Его результаты хуже в обеих категориях.

## Вопрос: 
**Кого из сотрудников стоит повысить?** 

## Теоритическое решение
Изначально из общей статистики, кажется, что программист А намного предпочтительней, ведь процент его выполненных задач и в простых и сложных больше, чем у программиста Б



* Программист А: $\frac{216}{220} = 98.2\\%$

Программист Б: $\frac{157} / 200 = 78.5\\%$

Парадокс: А лучше в каждой категории и в целом. Где же подвох?
